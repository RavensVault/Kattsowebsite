# Site vitrine de Kattso

Site statique en français, sans dépendance ni étape de compilation.

## Prévisualiser sur l'ordinateur

Depuis ce dossier, démarre un serveur local avec :

~~~powershell
python -m http.server --bind 127.0.0.1 8000
~~~

Puis ouvre http://localhost:8000. Pour arrêter le serveur, retourne dans sa fenêtre et appuie sur Ctrl+C.
Cette commande est réservée à la prévisualisation locale : ne redirige pas les ports de ta box vers ce serveur.

## Informations légales

- Les mentions belges affichent le pseudonyme et le contact. Elles n'affichent pas le nom civil ni l'adresse privée sur la base du projet personnel actuellement non rémunéré décrit par l'éditeur. Si l'activité devient économique ou rémunérée, réévaluer cette option.
- La page mentions-france.html est rédigée pour l'option d'anonymat des éditeurs non professionnels. Avant de l'utiliser, choisir un hébergeur tiers et remplacer le champ d'hébergement à compléter par son nom et son adresse. Si le site reste auto-hébergé, vérifier l'application de l'exception avant de basculer.
- Après le déménagement en France, dans app.js remplacer la destination mentions-belgique.html du lien unique « Mentions légales » par mentions-france.html.
- Les liens officiels fournis pour les réseaux sociaux sont déjà présents dans reseaux.html.
- Revoir les informations sur l'hébergement et les données techniques lorsque la configuration publique sera définie.

Les fichiers de marque et illustrations utilisés par le site se trouvent dans assets/.
